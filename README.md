# ResuMatch Agent

🧠 An AI-powered resume matching assistant that helps users compare resumes with job descriptions and identify skill gaps.

## 🔍 Features
- Upload your resume and a job description to get a match score.
- Highlights missing skills and keywords.
- Uses OpenAI and vector similarity search for analysis.
- Built with React, Node.js, and Express.

## 🚀 Tech Stack
- Frontend: React, TailwindCSS  
- Backend: Node.js, Express.js  
- AI: OpenAI API  
- Database: MongoDB
